# Autoevaluación por módulo

Califica 1–4 y aporta evidencia:

1. Puedo explicarlo.
2. Puedo reconocerlo en casos.
3. Puedo aplicarlo.
4. Puedo evaluar si funciona.
5. Puedo adaptarlo a otro contexto.
6. Puedo enseñar este conocimiento a otra persona.

No declares dominio sin un producto verificable.
