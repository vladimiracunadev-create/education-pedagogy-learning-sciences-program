# Evaluación del programa

Instrumentos para evaluar el propio avance y para evaluar a otros con el material del programa.

| Instrumento | Para qué |
|---|---|
| [Rúbrica maestra](MASTER-RUBRIC.md) | evaluar cualquier evidencia de aprendizaje del programa |
| [Autoevaluación](SELF-ASSESSMENT.md) | cerrar una parte con honestidad antes de avanzar |

El sistema completo —qué se evalúa, con qué criterios, cómo calibrar entre evaluadores y qué
evidencia exige cada etapa— está en
[docs/SISTEMA_DE_EVALUACION.md](../docs/SISTEMA_DE_EVALUACION.md).

## Regla de uso

- La rúbrica se entrega **antes** de pedir el trabajo, nunca después.
- Un `Insuficiente` en el criterio de **responsabilidad** invalida la evidencia completa.
- Si evalúas a otras personas, calibra con un segundo evaluador sobre tres trabajos reales antes
  de calificar: la clase 138 explica el procedimiento.
