# Virtual School Lab

Entorno de simulación longitudinal.

## Roles progresivos

1. educador/a de párvulos;
2. profesor/a básico;
3. profesor/a de educación media;
4. docente TP;
5. formador/a de adultos;
6. profesor/a universitario;
7. coordinador/a académico;
8. líder educativo;
9. investigador/a;
10. supervisor/a de tesis;
11. formador/a de docentes.

## Mecánica

Cada ciclo entrega:

- contexto institucional;
- estudiantes;
- evidencias;
- restricciones;
- incidente o desafío;
- decisión requerida;
- consecuencias simuladas;
- reflexión y mejora.

## Principio

No existe una respuesta universal. Se evalúa razonamiento profesional, calidad de evidencia, inclusión, proporcionalidad, ética y capacidad de aprender de resultados.
