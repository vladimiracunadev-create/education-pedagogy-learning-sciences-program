# Tutor educativo con IA

## Propósito

Diseñar criterios para un tutor seguro, verificable y pedagógicamente útil.

## Ciclo

1. Leer contexto.
2. Identificar evidencia.
3. Formular hipótesis.
4. Elegir intervención.
5. Definir indicador.
6. Revisar consecuencias.
7. Reflexionar y repetir.

## Regla

El simulador no premia respuestas "bonitas". Premia decisiones justificadas, proporcionales, inclusivas y evaluables.
