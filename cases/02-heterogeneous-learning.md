# Caso — Alta heterogeneidad

## Situación

El curso combina estudiantes adelantados, rezagados y con apoyos.

## Tareas

1. Separar hechos de interpretaciones.
2. Formular tres hipótesis explicativas.
3. Indicar qué evidencia adicional necesitas.
4. Proponer una intervención de bajo riesgo.
5. Diseñar un indicador de seguimiento.
6. Anticipar efectos no deseados.
7. Explicar cuándo derivar o pedir apoyo especializado.
