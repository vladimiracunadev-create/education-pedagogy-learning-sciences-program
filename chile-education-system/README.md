# Sistema educativo chileno

Esta sección estudia el marco chileno desde la práctica educativa. Debido a que leyes, decretos, orientaciones y procedimientos pueden modificarse, toda aplicación real debe verificarse contra su versión oficial vigente.

## Carpetas

- `01-system-map.md`: actores e instituciones.
- `02-curriculum.md`: bases, planes, programas y objetivos.
- `03-teacher-frameworks.md`: referentes de desempeño profesional.
- `04-assessment-regulation.md`: evaluación, calificación y promoción.
- `05-inclusion.md`: inclusión, diversificación y apoyos.
- `06-professional-development.md`: carrera y desarrollo profesional.
- `07-school-leadership.md`: liderazgo y gestión.
- `08-source-verification-checklist.md`: cómo validar normativa vigente.

Biblioteca del Congreso Nacional, MINEDUC, Currículum Nacional, CPEIP, Agencia de Calidad, Superintendencia de Educación y CNA.
