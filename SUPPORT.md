# Soporte

## Antes de preguntar

1. Revisa [docs/PREGUNTAS_FRECUENTES.md](docs/PREGUNTAS_FRECUENTES.md).
2. Busca en el [índice de archivos](FILE_INDEX.md) o en el buscador del sitio publicado.
3. Si es una duda de contenido, revisa la clase correspondiente en [SYLLABUS.md](SYLLABUS.md).

## Dónde preguntar

| Situación | Dónde |
|---|---|
| Error factual en una clase | *issue* con la etiqueta `contenido`, indicando la fuente correcta |
| Enlace roto, error de formato o de generación | *issue* con la etiqueta `bug` |
| Problema de accesibilidad | *issue* con la etiqueta `accesibilidad`: tienen prioridad |
| Duda sobre cómo usar el programa | *issue* con la etiqueta `pregunta` |
| Uso comercial o institucional del contenido | contacto directo con el autor: la licencia no permite uso comercial sin autorización |

## Qué incluir en un reporte

- Qué archivo o clase (número o ruta).
- Qué esperabas y qué ocurrió.
- Si es técnico: sistema operativo, versión de Python y comando ejecutado.

## Tiempos

Es un proyecto mantenido por una persona. Los reportes de accesibilidad y los errores factuales
con fuente se atienden primero.

## Lo que este proyecto no ofrece

- Asesoría pedagógica individual para casos reales con estudiantes.
- Certificación, validación de horas ni convalidación académica.
- Soporte para plataformas LMS de terceros: el paquete se entrega y la carga es responsabilidad
  de cada institución.
