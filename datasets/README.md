# Datasets

Datos sintéticos destinados a prácticas de evaluación, analítica e investigación.

**No contienen datos personales reales.**

Preguntas sugeridas:

- ¿Existe asociación entre asistencia y desempeño?
- ¿Quién mejora más entre diagnóstico y evaluación final?
- ¿Qué estudiantes requieren evidencia adicional antes de intervenir?
- ¿Qué variables no están disponibles y serían necesarias?
